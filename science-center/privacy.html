Privacy policy: Science Center publisher

Last updated 1 November 2026

Science Center publisher is a private tool that uploads videos to the Science Center YouTube channels. Only the owner of those channels uses it. It is not offered to the public and has no users other than the channel owner.

What the tool accesses

When the channel owner connects a channel, the tool asks Google for permission to:

  • upload videos to that channel (youtube.upload);
  • add captions and a thumbnail to those videos, add them to the channel's playlists, and update their descriptions (youtube.force-ssl).

It uses this access only to publish videos the channel owner has reviewed and approved, and to keep the links in their descriptions up to date. It does not read viewers' data, comments, subscribers, analytics, or any other account's data.

What is stored

  • A refresh token for each connected channel, so uploads can run without signing in each time. It is stored encrypted in the channel owner's Azure Key Vault and is never shared.
  • The ID and link of each uploaded video, kept with the project's own records.

No personal data about viewers or any other person is collected, stored or shared.

Removing access

The channel owner can revoke the tool's access at any time at myaccount.google.com/permissions, and delete the stored token from Azure Key Vault.

Google API Services

Use of information received from Google APIs follows the Google API Services User Data Policy, including its Limited Use requirements.
